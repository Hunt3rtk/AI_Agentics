# Website

Astro + TypeScript + Tailwind + React islands site for the AI Agentics repository.

## Scripts

- `npm run dev` — start local development server
- `npm run build` — production build
- `npm run preview` — preview built output
- `npm run lint` — Astro type/content checks + TypeScript check
- `npm run test` — run Vitest test suite

## Run

```bash
npm install
npm run dev
```

## Verify

```bash
npm run lint
npm run test
npm run build
```
